# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
사용자가 요청한 정적 HTML, GitHub Pages 배포용 단일 폴더. 외부 서버 없이 HTML/CSS/JavaScript와 로컬 데이터 파일로 구현한다.

## Users
Previzion의 내부 품질·성능을 검토하는 사용자. 프로젝트별 기록과 전체 분포를 비교한다.

## Product Purpose
18개 프로젝트의 스토리보드 생성, 첫 씬 생성, 후속 요청 비용과 시간을 원자료부터 요약 통계까지 확인하고 다운로드한다.

## Capabilities and Constraints
기존 집계의 원값을 보존한다. 스토리보드는 당시 17건과 11월 8일 보충 1건을 구분한다. 씬 추가요청은 확인된 6건만 집계한다. 기록 부재를 0원으로 처리하지 않는다. 스토리보드 컷 재생성 36회와 전체 확장 1회는 별도 집계한다. 실제 배포는 이번 요청에 포함되지 않는다.

## Evidence on Hand
상위 폴더의 storyboard_stages_2026-11-07 및 scene_generation_18_2026-11-07의 CSV/JSON. 원본 로그에 있는 계정정보, 개인 경로, 인증정보, 요청 본문은 배포물에 복사하지 않는다. 실행별 측정값·모델·시각·run_id를 보존한다.

## Product Principles
평균의 분모와 측정 기준을 표시한다. 비용은 USD, 시간 원값은 초다. 과거 실측과 보충 실행을 구분한다. 작은 표본의 한계를 표시한다.

## Brand Commitments
사용자가 어두운 배경의 분석 대시보드를 선택했다.

## Report Copy
보고서 화면은 비용·시간·통계에 집중한다. 요구사항 루프와 버전 실험 등 개발 배경 설명은 넣지 않는다. 표본 수와 필수 측정 기준만 짧게 표시한다.

## Analysis
작업별 시간과 컷 수·영상 길이의 비용·시간 관계를 별도 목차로 제공한다. 기존 18개 측정과 추가요청 6회의 시간 로그를 사용한다. 첫 씬의 길이는 생성 요청 당시 길이이며 MP4 실측 길이가 아니다. 스토리보드 길이는 생성 결과 값으로 별도 분석한다. 원자료·불확실성·예외 제외 결과를 함께 제공한다.

## New Batch Comparison
2026.11.09–10 측정한 Claude Opus 5.5 AI 프리비즈, GPT-6 Sol AI 프리비즈, GPT-6 Sol 일반 모드를 각각 탭으로 제공한다. 기존 79개 관측값은 Claude 일반 모드라는 첫 탭·기본 화면에 보존한다. 기존 첫 씬 18건을 포함한 네 묶음 비교도 제공한다. 새 자료는 결과 54개·실행 55회이며 Claude의 실패·재시도와 사후 비용을 전체 비용에서 누락하지 않는다. 모델 완료 선언과 50턴 제한 종료를 구분하고 품질 판정으로 바꾸지 않는다. 네 묶음 요약 시간은 앱 / 클라이언트 타이머로 통일하고 서버 시간은 별도로 표시한다. 현재 152컷과 과거 148컷, 서로 다른 실행 시점을 명시하고 통제된 모델 성능 시험으로 표현하지 않는다. 배포에는 허용한 측정 필드만 포함하고 원본 계정·인증정보·개인 경로·요청 본문은 제외한다.

## Coverage Alignment
사용자는 색상만 적용한 이전 변경을 거절하고 coverage 보고서의 실제 화면 구성을 요구했다. 같은 차콜 배경·파란 선택 상태·초록/노랑/빨강 상태색과 일관된 SVG 아이콘을 사용한다. 약 73px 상단 메뉴, 238px 왼쪽 18개 프로젝트 목록, 38px 안쪽 여백의 본문을 맞춘다. 네 모델·모드 탭은 Claude 일반 모드부터 시작하며 프로젝트 선택 시 본문 상세가 바로 열린다. 모바일에서는 프로젝트 선택 상자와 2×2 모드 탭·비교값을 사용한다. 기존 분석 기능과 79개 측정값을 모두 유지한다.
