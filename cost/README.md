# Previzion 생성 비용·시간 대시보드

18개 프로젝트의 기존 측정과 새로 생성한 세 묶음을 탐색하는 정적 웹 보고서. coverage 보고서의 상단 메뉴·왼쪽 프로젝트 목록·본문 배치와 색상·아이콘을 맞췄으며 외부 라이브러리·API·폰트 서버 없이 동작한다.

## 열기와 배포

`index.html`을 브라우저로 열면 된다. `fetch()` 없이 로컬 JavaScript에 데이터를 포함하므로 파일을 직접 열어도 작동한다.

GitHub Pages에는 **이 폴더의 내용 전체**를 배포 루트로 올린다. `index.html`, `assets/`, `data/`, `.nojekyll`을 함께 유지한다. 모든 링크는 상대 경로라 저장소 하위 경로에서도 동작한다. 이번 작업은 배포용 파일 준비까지이며 GitHub에 업로드하거나 공개하지 않았다.

로컬 HTTP 미리보기:

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 연다. 별도 빌드나 npm 설치는 필요하지 않다.

## 새로 측정한 세 묶음 · 2026.11.09–10

첫 화면은 **Claude · 일반 모드**다. 기존 79개 기록과 상세 통계·시간·관계 분석을 이 첫 탭에 보존했다. 이어서 **Claude · AI 프리비즈**, **GPT-6 Sol · 일반 모드**, **GPT-6 Sol · AI 프리비즈**를 선택한다. 상단 **네 묶음 비교**는 기존 첫 씬 18건과 새 세 묶음을 함께 비교한다.

왼쪽 18개 프로젝트 목록에는 현재 모드의 최종 씬 비용을 표시한다. 프로젝트를 선택하면 본문에 상세 기록이 바로 열린다. 모바일에서는 선택 상자가 이 목록을 대신한다. 상단 메뉴로 전체 요약·네 묶음 비교·측정 기준을 열 수 있다.

| 묶음 | 실행 / 최종 결과 | 모델 완료 / 50턴 제한 | 전체 비용 USD |
|---|---:|---:|---:|
| Claude Opus 5.5 · AI 프리비즈 | 19 / 18 | 18 / 0 | 53.5203902 |
| GPT-6 Sol · AI 프리비즈 | 18 / 18 | 16 / 2 | 30.641127 |
| GPT-6 Sol · 일반 모드 | 18 / 18 | 10 / 8 | 39.127024 |

최종 결과 54개와 전체 실행 55회를 구분한다. Claude의 15번 첫 시도 실패와 재시도를 모두 보존했으며, 공급사 사후 조회 비용 0.0566702 USD도 전체 비용에 포함한다. 해당 실패 기록의 비용 exact는 false로 유지한다. 최종 결과 18개 비교에서는 실패 대신 재시도 결과를 사용한다.

각 탭은 검색·종료 사유 필터·비용/시간 정렬·실행 상세·CSV/JSON 다운로드를 제공한다. 비교 화면에서 비용/서버 시간/앱 시간을 전환하고 값을 선택하면 해당 기록이 열린다. 탭은 좌우 방향키·Home·End로 이동할 수 있다. 모바일에서는 네 비교값을 모드 이름과 함께 2×2로 표시하고, 실행표의 추가 수치는 프로젝트 상세에서 확인한다.

새 시간 통계의 기본값은 서버 타이머다. 앱 시간과 배치의 실제 경과 시간도 별도로 표시한다. 모든 조건은 high, 최대 50턴이며 같은 152컷·이미지 182개를 사용했다. 네 묶음 요약 비교는 모두 앱 / 클라이언트 시간으로 맞춘다. 기존 첫 씬 148컷과 새 측정 152컷은 입력·실행 시점이 달라 통제된 모델 성능 시험이 아니다. 각 묶음의 집계는 별도로 유지한다. 새 묶음의 P90은 nearest-rank 방식이며 기존 통계의 선형 보간 방식과 구분한다.

## 작업별 시간과 관계 분석

상단의 **작업별 시간**에서 첫 씬 18건·예외 제외 17건·추가요청 6건을 전환한다. 모델 응답/도구 실행 시간, 요청 종류별 비중, 긴 응답과 출력 한도 사례, 프로젝트별 상세와 스토리보드 단계별 분포를 제공한다. 첫 씬 525턴·1,047회 도구 호출, 추가요청 114턴·169회 호출의 기존 로그를 집계했다. 모델 응답 구간에는 통신·재시도·턴 저장도 포함되어 순수 추론 시간과 다르다.

**컷·길이 관계**에서는 단계·표본·가로축·세로축을 선택한다. Pearson r, Spearman ρ, Fisher z 근사 95% 신뢰구간, 200,000회 양측 순열 p, Holm 보정 p, 단순 회귀 기울기와 R²를 제공한다. 전체 18건의 8개 비교를 한 집단으로 보정하고, 예외 제외는 각 단계의 4개 비교를 별도로 보정한다. 순열 시드는 `tools/build_analysis.py`에 고정했다.

첫 씬의 영상 길이는 **생성 요청 당시 길이**이며 최종 MP4 실측 길이가 아니다. 스토리보드는 **그 실행에서 생성된 스토리보드 길이**이므로 사전에 고정된 설명변수가 아니다. 첫 씬의 예외는 공룡에게 츄르를, 스토리보드의 예외는 야간 인수인계 보충 측정이다. 추가요청은 3개 프로젝트의 반복 관측이므로 관계 분석에 합치지 않는다. 상관관계는 인과 효과를 뜻하지 않는다.

## 파일 구성

- `index.html`, `assets/style.css`, `assets/app.js`: 화면과 상호작용.
- `assets/coverage.css`, `assets/coverage.js`: coverage와 같은 상단 메뉴·프로젝트 목록·본문 배치와 화면 전환.
- `assets/data.js`: 로컬 파일 열기를 지원하는 통합 데이터.
- `data/report.json`: 화면에 사용하는 통합 데이터와 측정 정의.
- `data/runs.csv/json`: 79개 요청·실행 관측값의 모든 배포 대상 측정 필드.
- `data/projects.csv/json`: 프로젝트별 세 단계 비용·시간과 추가요청 합계·평균.
- `data/statistics.csv/json`: 통계 대상별 모든 기술통계.
- `data/timing.json`, `data/timing-projects.csv`, `data/timing-turns.csv`, `data/timing-tools.csv`: 작업별 시간 통계와 실행·턴·도구 호출 원자료.
- `data/relationships.json`, `data/relationship-points.csv`, `data/relationship-statistics.csv`: 관계 분석 전체, 프로젝트별 분석 입력, 16개 상관·회귀 결과.
- `data/storyboard.csv`, `data/scene.csv`, `data/followup.csv`, `data/panel.csv`, `data/expansion.csv`: 작업별 원자료.
- `data/source/`: 기존 보고서의 측정 원값, 원래 통계와 컷 수 분석. 계정명·개인 경로·요청 본문을 제외했다.
- `data/provenance.json`: 원래 집계 파일명과 SHA-256, 제외한 필드.
- `data/manifest.json`: 배포 데이터 파일의 크기와 SHA-256.
- `data/all-data.zip`: 위 데이터 전체 다운로드.
- `tools/build_data.py`: 동봉한 원자료에서 파생 데이터·통계·ZIP을 다시 만드는 코드. 네트워크와 유료 생성 호출 없음.
- `tools/build_analysis.py`, `assets/analysis.js`, `assets/analysis.css`: 작업별 시간 및 관계 분석 계산·표·산점도.
- `tools/build_batches.py`, `assets/batches.js`, `assets/batches.css`: 새 세 묶음의 집계·탭·비교와 상세 조회.
- `assets/batches-data.js`, `data/batches.json`: 새 세 묶음과 기존 첫 씬 비교용 baseline의 공개 가능한 측정값. 계정·인증정보·개인 절대경로·요청 원문 제외.
- `data/mode-comparison.csv/json`: 기존 Claude 일반 모드를 포함한 네 묶음 비교. 원래 79개 자료는 변경하지 않고 첫 씬 18건만 참조한다.
- `data/batch-runs.csv`, `data/batch-comparison.csv`, `data/batches-provenance.json`: 55회 실행, 묶음별 비교, 원자료 해시.
- `data/claude-ai.json`, `data/gpt-ai.json`, `data/gpt-normal.json` 및 `*-runs.csv`: 묶음별 다운로드.
- `.impeccable/`, `PRODUCT.md`, `DESIGN.md`: 화면 설계·검수 기록. 서비스 실행에 필요하지 않다.

## 재계산

이 폴더에서 아래를 실행한다. Python 표준 라이브러리만 사용한다.

```sh
python3 tools/build_data.py
python3 tools/build_batches.py
```

`data/source/`는 바꾸지 않고 나머지 파생 데이터, `assets/data.js`, ZIP과 데이터 해시를 갱신한다. 비용의 다섯 작업별 합계를 기존 집계와 대조하며 달라지면 중단한다. 표본을 추가하는 경우에는 고정된 표본 수·기준 합계와 HTML 안내문도 함께 갱신해야 한다.

`build_batches.py`는 워크스페이스의 상위 폴더에 있는 세 측정 디렉터리의 `runs.json`, `runs.csv`, `statistics.json`, 검증·버전·시작 이벤트를 읽는다. 실행별 비용 합계와 모드·모델·보존 검증을 대조하고, 배포용 측정 필드만 골라 JSON·CSV·ZIP을 만든다. 새 API 호출은 없다. 동봉된 정적 보고서를 열 때는 재계산하지 않아도 된다.

## 해석

스토리보드는 서버 경과 시간, 씬은 클라이언트 경과 시간이다. 서로 다른 시점·환경의 관측이며 같은 사용자의 연속 대기 시간으로 합산하지 않는다. 비용은 기록된 API 비용이며 인프라·렌더·인건비·판매 가격을 포함하지 않는다. 과금 원장 전체나 미선정 실행 로그 대신, 이 보고서에 사용한 실행 단위 측정 원자료를 제공한다.

기존 화면은 비용 소수점 셋째 자리·시간 초 단위로 반올림한다. 새 묶음과 네 묶음 비교는 비용 최대 소수점 여덟 자리, 비교표의 프로젝트별 비용은 네 자리로 표시한다. 원자료와 JSON은 원래 정밀도를 보존한다. 기존 사분위·백분위는 선형 보간, 표준편차는 n−1 분모이며 n=1에서는 정의하지 않는다. 추가요청 합계·평균은 해당 프로젝트의 관측된 요청만 사용한다.
