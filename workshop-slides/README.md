# H.I.S. 운영진 워크샵 슬라이드

`index.html`을 브라우저에서 직접 열거나, 이 폴더를 로컬 웹 서버로 제공해 실행합니다.

## 탐색

화살표 키, Space, PageUp/PageDown, Home/End, 좌우 스와이프, 하단의 전체 화면 버튼을 사용해 슬라이드를 탐색할 수 있습니다.

## 편집

사진, 팀 소개, 공지 이미지, 카훗 QR은 각 슬라이드에 표시된 이름의 교체 영역 안에서만 파일 또는 마크업을 교체합니다. 규정에서 가져온 문구의 출처 노트는 보존합니다. 제공된 세 개의 원본 문서에 없는 내용을 추가할 때는 `AI 보완` 표기를 유지하거나 추가합니다.

이 초안에는 타이머와 네트워크 의존성이 없습니다.
